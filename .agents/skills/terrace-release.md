# Terrace Release Skill

## Overview

This skill covers stable promotion, image signing, cosign verification, and rollback procedures for Terrace images.

Terrace follows the Project Bluefin Dakota release model: automated Friday promotion from `testing` to `stable` with full cryptographic supply chain.

## Release Streams

| Stream | Tag Pattern | Purpose |
|--------|-------------|---------|
| `testing` | `testing-{version}-{arch}-{variant}` | Daily builds, PR validation |
| `stable` | `stable-{version}-{arch}-{variant}` | Friday-promoted, production |
| `latest` | `latest-{arch}-{variant}` | Alias to latest testing |

## Promotion Process (Friday)

### Automated (execute-release.yml)
1. **Schedule**: Every Friday 6 AM UTC
2. **Verify**: All testing images exist for version
3. **Test**: Run smoke tests on testing images
4. **Promote**: Re-tag testing → stable + latest
5. **Sign**: Cosign sign + SBOM + SLSA L2
6. **Chunkah**: OCI layer rechunking
7. **Scan**: Trivy vulnerability scan
8. **Release**: GitHub Release with changelog
9. **Update**: `.github/release-state.yaml`

### Manual Trigger
```bash
gh workflow run execute-release.yml -f version=26.08.1
```

## Signing

### Cosign Keyless Signing
```bash
# Uses GitHub OIDC token for identity
cosign sign --yes ghcr.io/huntedraven7/terrace/plateau:stable-26.08.1-x86_64-default
```

### Verification
```bash
cosign verify ghcr.io/huntedraven7/terrace/plateau:stable-26.08.1-x86_64-default \
  --certificate-identity-regexp "https://github.com/huntedraven7/terrace" \
  --certificate-oidc-issuer "https://token.actions.githubusercontent.com"
```

### SBOM
Generated by `syft` during `sign-and-publish`:
```bash
cosign download sbom ghcr.io/huntedraven7/terrace/plateau:stable-26.08.1-x86_64-default
```

### SLSA Provenance
SLSA Build L2 attestation:
```bash
cosign verify-attestation --type slsaprovenance \
  ghcr.io/huntedraven7/terrace/plateau:stable-26.08.1-x86_64-default
```

## Version Tagging

### Format
```
testing-26.08.1-x86_64-default
stable-26.08.1-x86_64-default
latest-x86_64-default
```

### Version Source
Single source of truth: `elements/freedesktop-sdk.bst` FSDK pin
```bash
# Extract version
grep -oE 'freedesktop-sdk-[0-9]+\.[0-9]+\.[0-9]+' elements/freedesktop-sdk.bst | head -1 | sed 's/freedesktop-sdk-//'
# Output: 26.08.1
```

## Rollback Procedure

### Automated (rollback-stable.yml)
```bash
gh workflow run rollback-stable.yml -f version=26.08.0
```

### Manual
```bash
# Re-tag previous stable as current
skopeo copy --all \
  docker://ghcr.io/huntedraven7/terrace/plateau:stable-26.08.0-x86_64-default \
  docker://ghcr.io/huntedraven7/terrace/plateau:stable-26.08.1-x86_64-default

# Re-sign
cosign sign --yes ghcr.io/huntedraven7/terrace/plateau:stable-26.08.1-x86_64-default
```

## Changelog Generation

Uses `git-cliff` (via `generate-release-notes` action):
```toml
# cliff.toml
[changelog]
header = "# Terrace Changelog"
body = """
{% for version, commits in commits | group_by(attribute="version") %}
## {{ version.timestamp | date(format="%Y-%m-%d") }} - {{ version }}
{% for commit in commits %}
- {{ commit.message }} ({{ commit.id | truncate(length=7) }})
{% endfor %}
{% endfor %}
"""
```


## Anti-patterns (DO NOT)
- ❌ Promote without smoke tests
- ❌ Publish stable without signing
- ❌ Use mutable tags for stable
- ❌ Skip Trivy scan for stable
- ❌ Manual tag manipulation without workflow
