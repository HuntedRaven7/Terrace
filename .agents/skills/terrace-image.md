# Terrace Image Skill

## Overview

This skill covers OCI layer composition, boot testing, VM checks, and OTA update mechanics for Terrace images.

Terrace produces two bootc-compatible OCI images:
- **Plateau** — Desktop image (Mango WM + Quickshell)
- **Strata** — Server image (k0s sysext + Kubestellar)

Both are assembled via BuildStream `kind: compose` elements from FSDK 26.08.1 components.

## Image Structure

### Plateau (Desktop)
```
oci/plateau.bst (kind: compose)
  → plateau/deps.bst (kind: stack)
    → freedesktop-sdk:runtime + platform
    → core/linux-fdsdk.bst (or linux-ogc.bst for gaming)
    → System: systemd, flatpak, portals, polkit, dbus
    → Graphics: mesa, vulkan, wayland, wlroots, xwayland
    → Audio: pipewire, wireplumber, alsa
    → Desktop: mango, quickshell, rofi, awww, pipewire, wlclipboard
    → Terminal: foot
    → File Manager: thunar
    → Browser: firefox
    → Utils: grim, slurp, mako, swaylock, swayidle
```

### Strata (Server)
```
oci/strata.bst (kind: compose)
  → strata/deps.bst (kind: stack)
    → freedesktop-sdk:runtime + platform
    → core/linux-fdsdk.bst
    → System: systemd, systemd-sysupdate, systemd-repart, flatpak
    → Shell: bash, uutils-coreutils, util-linux
    → Networking: networkmanager, openssh, firewalld, iproute2
    → Filesystems: e2fsprogs, btrfs-progs, xfsprogs, cryptsetup
    → Containers: podman, buildah, skopeo, crun, runc, containerd
    → Kubernetes: kubectl, helm
    → Server: k0s-sysext, kubestellar, ucore-base, server-install
```

## Bootc Integration

### bootc.json Metadata
Each image includes `/etc/bootc/bootc.json`:
```json
{
  "bootc": {
    "version": "26.08.1",
    "image": "ghcr.io/huntedraven7/terrace/plateau",
    "variant": "plateau"
  }
}
```

### OS Release
`/etc/os-release` identifies the variant:
```
VARIANT="plateau"
VARIANT_ID="plateau"
```

### Enabled Services (Strata)

`.github/workflows/e2e.yml` runs:

2. Boot in QEMU with KVM
3. Verify services start
4. Run image-specific test scripts

## OTA Updates

### Update Flow
1. New image published to GHCR with version tag
2. User runs `bootc upgrade`
3. bootc pulls new image, stages deployment
4. Reboot activates new deployment
5. `bootc status` shows current/pending

### Rollback
```bash
bootc rollback
# Or specific deployment:
bootc switch <deployment-id>
```

### Chunkah Optimization
- CI runs `chunka` action on publish
- Reorganizes OCI layers for max reuse
- Reduces download size on upgrade

## Image Signing

### Cosign Signing (Stable)
```bash
cosign sign --yes ghcr.io/huntedraven7/terrace/plateau:stable-26.08.1-x86_64-default
```

### SBOM Generation
- `syft` generates SPDX SBOM
- Attached as cosign signature

### SLSA Provenance
- SLSA Build L2 provenance attestation
- Generated by `sign-and-publish` action

## Common Tasks

### Inspect Image
```bash
# Manifest
skopeo inspect docker://ghcr.io/huntedraven7/terrace/plateau:testing-26.08.1-x86_64-default

# Layers
skopeo inspect --raw docker://ghcr.io/huntedraven7/terrace/plateau:testing-26.08.1-x86_64-default | jq '.layers'
```

### Verify Signature
```bash
cosign verify ghcr.io/huntedraven7/terrace/plateau:stable-26.08.1-x86_64-default \
  --certificate-identity-regexp "https://github.com/huntedraven7/terrace" \
  --certificate-oidc-issuer "https://token.actions.githubusercontent.com"
```

### Export for Offline
```bash
just export-plateau
# Outputs to dist/oci/plateau/
```

## Anti-patterns (DO NOT)
- ❌ Modify image after BuildStream assembly
- ❌ Skip boot testing
- ❌ Publish unsigned images as stable
- ❌ Use mutable tags for production
- ❌ Hardcode registry in elements
